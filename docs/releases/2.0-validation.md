# ClayFighter 64 2.0 validation

Own work: **djultra64**. Release: October 14, 2026 (America/Mexico_City).

## Final native builds

The final Linux build passed **48/48 CTest checks**. The final Windows x64 MSVC
build passed **62/62 CTest checks**. The suites cover Training rules, selection
and visible cursors, stage navigation, native pause/options, input glyphs and
alignment, portable paths, settings persistence, native audio-volume application,
original Options defaults, native input recognition and scene reset.

All 28 original Options values passed persistence, profile isolation, validation
and reset-defaults checks. The actual original CPU initializer agrees with every
stored default. Music/FX restore calls apply to the native mixer and music
sequences. Linux runtime checks changed Music Level, FX Level, difficulty and
Spillits through Options, then restored the saved values in a separate process.

Two final Linux Training runs reached native combat and the simplified pause
menu and completed without stalls. GPU captures show Damage, Combo and Hits in
three separate rows above left-side input history, aligned number/icon baselines,
and controller glyphs in the pause footer. The selector fixtures execute 512
P1/opponent position and confirmation combinations with native cursor draws;
GPU captures show both cursors during selection.

The final Windows Training run lasted 90 seconds, reached combat and ended
normally with 5,382 graphics submissions and 9,908 input polls. Windows Options
save/restart runs lasted 42 and 30 seconds: music 19687, SFX/voice 26221 and Spillits 1
were restored exactly, and the saved file remained byte-for-byte identical.

## Packaged Windows installation

The Windows package imported both supported USA ROMs into a clean folder.
The imported base image, combined roster image and biographies matched their
verified counterparts. After moving the folder to a new path containing spaces,
the packaged launcher completed a 20-second native run with exit 0 and 1,142
graphics submissions. The packaged executable matched the final build hash.
Game-managed settings use the installation-local profile directory.

## Packaging and source correspondence

The 11 public-release/importer checks passed, including two-ROM normalization,
identity verification, asset parity, portable path boundaries, manifest assembly
and source exclusions. Executable SHA-256 values and matching host-source
inventories are recorded in config/dependencies-2.0.json. The authorized Windows
source audit matched 261 synchronized files with zero differences.

Binary packages include file manifests; SHA256SUMS covers release archives.
The authored source and matching SDK/dependency source archives preserve
original third-party notices. Installation generates the combined cartridge
assets locally from both supported USA games.
